# OpenGuardian

OpenGuardian began as a personal research project (2023–2026) focused on reverse engineering Medtronic insulin pumps and CGM transmitters.

The project has since evolved into a broader community collaboration. Ongoing development, documentation, and related repositories are now maintained under the OpenMinimed organization:

[https://github.com/orgs/OpenMinimed/repositories](https://github.com/orgs/OpenMinimed/repositories)
